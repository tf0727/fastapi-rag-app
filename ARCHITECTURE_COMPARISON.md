## 详细流程对比

### 场景 1：价格范围查询

| 步骤 | 旧架构 | 新架构 |
|-----|--------|--------|
| 1. 查询理解 | ❌ 不理解"价格范围" | ✅ LLM 识别为价格查询 |
| 2. 参数提取 | ❌ 无法提取 3000-5000 | ✅ 自动提取 min=3000, max=5000 |
| 3. 搜索方法 | 混合搜索（不适合） | 价格范围搜索（最优） |
| 4. 过滤效果 | 文本匹配，不精确 | Range Query，精确过滤 |
| 5. 结果质量 | 中 | 高 |

### 场景 2：类别查询

| 步骤 | 旧架构 | 新架构 |
|-----|--------|--------|
| 1. 查询理解 | ❌ 不理解"类别" | ✅ LLM 识别为类别查询 |
| 2. 类别提取 | ❌ 无法提取 | ✅ 提取："智能穿戴" |
| 3. 搜索方法 | 混合搜索 | Term Query（精确匹配） |
| 4. 结果准确性 | 可能包含其他类别 | 100% 匹配该类别 |
| 5. 性能 | 中 | 高 |

### 场景 3：相似产品查询

| 步骤 | 旧架构 | 新架构 |
|-----|--------|--------|
| 1. 查询理解 | ❌ 不理解"相似" | ✅ LLM 识别相似产品查询 |
| 2. 产品提取 | ❌ 无法提取参考产品 | ✅ 提取："小米14" |
| 3. 搜索方法 | 混合搜索 | 向量相似度搜索 |
| 4. 相似度计算 | 基于文本 | 基于 embedding |
| 5. 结果相关性 | 低 | 高 |
